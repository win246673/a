# 多功能工具集

一款简洁实用的多功能工具集Web应用，包含计算器、待办事项、记账本等常用工具，支持深浅色主题切换和数据导入导出功能。

## 项目介绍

本项目是一个轻量级的一站式工具集，将日常生活中常用的计算器、待办事项管理和记账功能整合在一起，无需安装即可在浏览器中直接使用。所有数据都会自动保存在本地（localStorage），确保您的数据隐私安全。

## 功能列表

### 1. 计算器
- 支持加、减、乘、除四则运算
- 支持小数点输入
- 显示计算历史记录
- 记录使用次数统计

### 2. 待办事项
- 添加/删除待办事项
- 设置优先级（高/中/低）
- 标记完成/未完成
- 筛选显示（全部/待完成/已完成）
- 实时统计待办总数和完成率
- 支持回车键快速添加

### 3. 记账本
- 记录收入和支出
- 实时计算余额
- 显示收支统计卡片
- 删除记录功能
- 记录次数统计

### 4. 使用统计
- 各工具使用次数统计
- 待办完成率展示
- 收支汇总展示
- 最近操作记录展示

### 5. 关于我（简历页面）
- 个人基本信息展示
- 技能标签展示
- 工作经历展示
- 项目经验展示

### 6. 全局功能
- **深色/浅色主题切换**：一键切换，无样式错乱
- **数据导入/导出**：支持JSON格式备份和恢复
- **最近使用记录**：记录各工具使用时间
- **响应式布局**：完美适配手机和电脑端

## 技术实现

- **前端框架**：原生HTML + CSS + JavaScript
- **数据存储**：localStorage本地存储
- **主题系统**：CSS变量 + data-theme属性
- **布局方案**：CSS Grid + Flexbox响应式布局

## 使用说明

### 计算器
1. 点击数字按钮输入数字
2. 点击运算符进行计算
3. 点击 "=" 获取结果
4. 点击 "C" 清空显示
5. 点击 "DEL" 删除最后一位

### 待办事项
1. 输入待办内容
2. 选择优先级
3. 点击"添加"或按回车键添加
4. 点击复选框标记完成
5. 使用筛选按钮查看不同状态的待办

### 记账本
1. 选择收入或支出类型
2. 输入金额和说明
3. 点击"记录"添加
4. 查看顶部统计卡片了解收支情况

### 数据备份
1. 点击右上角的 📤 按钮导出数据
2. 点击 📥 按钮导入之前备份的数据
